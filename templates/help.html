How to use — step by step

A simple guide for your first filing. Follow the five steps in order. It takes about 20 minutes.

1. Download reports 2. One folder 3. Process here 4. Upload GSTR-1 5. GSTR-3B FAQ
{# ================= STEP 1 ================= #}
1

Download your monthly reports

Do this once every month. You need up to 7 files from 4 websites. Menu names can change a little.

Amazon 2 files from Seller Central
  • Seller Central → Reports → Tax Document Library → Merchant Tax Report (MTR) B2C — pick your month. You get a CSV. It has the invoice numbers for Table 13.
  • Seller Central → GST Reports → "GST Ready-to-File Reports" → Download Report. You get an xlsx. It has B2CS, B2CL and HSN data.
Flipkart 2 files from Seller Hub
  • Seller Hub → Reports → GST Reports → GSTR return report. You get an xlsx with the official monthly totals and HSN.
  • Seller Hub → Reports → Sales Report. You get an xlsx. It is needed for the credit-note series.
Meesho 2 zip files from Supplier Panel
  • Supplier Panel → Download → GST Report. You get a zip. Inside it: tcs_sales.xlsx and tcs_sales_return.xlsx.
  • Supplier Panel → Download → Supplier Tax Invoice. You get a zip. Inside it: Tax_invoice_details.xlsx.
GST Portal 1 file — needed for GSTR-3B ITC
  • services.gst.gov.in → login → Returns Dashboard → select month → GSTR-2B tile → Download → "GENERATE JSON FILE TO DOWNLOAD". You get a .json file. The app uses it for GSTR-3B Table 4 (ITC).
{# ================= STEP 2 ================= #}
2

Put everything in ONE folder

Make one folder on your computer. Move all the files you downloaded into it.

  • Zips do NOT need extraction. The app opens them itself.
  • Do not mix months in one folder. The tool excludes wrong-month files and warns you.
  • Keep the original file names. Do not rename the downloads.
{# ================= STEP 3 ================= #}
3

Process in this app

Give the app your files. It reads them and builds the portal JSONs for you.

  1. Choose your folder. Click "Browse folder" and pick the folder with all your downloaded files. The app shows which files it will upload. Then click "Upload & process".
    2. {% else %}
  2. Paste your folder path. Copy the path of your folder from Step 2. Paste it in the "Reports folder" box. Or click "Browse folder" and pick the folder.
    3. {% endif %}
  3. Type the month (optional). Use MMYYYY, like 062026 for June 2026. Or leave it blank — the app finds the month itself.
  4. Click Process. Wait a few seconds. The results page opens.

How to read the results page

  • error Every red message = something to fix. Fix it and process again.
  • warning Yellow = read it and decide. The app still made the files.
  • ok Green = all good.
  • The platform tiles show what was found and what is missing for Amazon, Flipkart and Meesho.
  • The File scan table at the bottom shows every file. It tells you why each file was used or skipped.
  • Each result card is one GSTR-1 table. Use Copy JSON or Download on the card you need.
{# ================= STEP 4 ================= #}
4

Upload GSTR-1 on the GST portal

Take the full JSON file from Step 3 and upload it on the portal.

  1. Login at services.gst.gov.in.
  2. Go to Returns Dashboard → pick your month → open the GSTR-1 tile.
  3. Click "PREPARE OFFLINE".
  4. Click Upload → Choose File. Select the downloaded gstr1_full_<month>.json file.
  5. Wait. The portal takes a few minutes to process the file.
  6. Go back to the GSTR-1 online view. Check the tables against the app's cards: Table 5 (B2CL), Table 7 (B2CS), Table 12 (HSN), Table 13 (Documents).
  7. Click Generate Summary → Submit → File with EVC or DSC.
Be careful before you file. Uploading the JSON replaces the matching sections already on the portal for that month. Check every table first. Filing is final — it cannot be undone.
{# ================= STEP 5 ================= #}
5

GSTR-3B — after GSTR-1 is filed

The portal makes a draft GSTR-3B for you. Your job is to check it.

  1. File GSTR-1 first (Step 4). The portal then auto-drafts GSTR-3B from your GSTR-1 and GSTR-2B.
  2. Open the app's GSTR-3B card. Check each table value on the portal: 3.1(a) outward supplies, 3.2 state-wise supplies, and Table 4 ITC.
  3. The app's JSON can also be used with the GSTR-3B offline utility.
  4. Accept your TCS credit separately: Services → Returns → "TDS and TCS credit received".
No GSTR-2B JSON given? Then the app leaves Table 4 out on purpose. Use the portal's auto-drafted ITC instead.

Common questions

Click a question to see the answer.

The app excluded my file and said "wrong month"

That file belongs to a different month. The app keeps one month per run, so your JSON stays clean.

Move files from other months to another folder. Then process again. Check the File scan table to see which file was excluded.

A state row is negative — is that a problem?

This happens when returns were more than sales in that state for that month. The app shows a yellow warning for it.

Check the row and your return data first. If the portal does not accept the negative value, talk to your tax advisor about adjusting it in a later month.

HSN tax was corrected — why?

Platform HSN sheets sometimes show gross tax on free promo shipments. The tax looks too big for the taxable value.

The app fixes it: tax = taxable value × rate. It also tells you when it did this, so you can check.

Which file gives invoice numbers for Table 13?

Amazon: the MTR B2C CSV from the Tax Document Library.

Meesho: Tax_invoice_details.xlsx, inside the Supplier Tax Invoice zip.

Flipkart: the Sales Report xlsx is needed for the credit-note series.

Yes. Everything stays on your computer. The app runs locally. Your reports never leave your machine.

Do I need to extract the zip files?

No. Put the zips in the folder as they are. The app opens them itself.

The portal shows different totals than the app

First read the yellow warnings on the results page. They often explain the difference.

Then check the File scan table. Make sure every platform file was included and none was skipped. Fix and process again if needed.
